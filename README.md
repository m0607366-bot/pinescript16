# Hiropi_Skya 再現版（RCI × ADX スキャルピング）

YouTube「FXトレードルーム」で紹介された「ヒロピースキャ V2」を、設定画面と書き出しデータから推定して再現したものです。原作のコードは非公開です。
開発は skills-fx の流れ（Pineインジケーター → Pineストラテジー → Python検証 → cTrader cBot）に沿って進めます。

## フォルダ

| フォルダ | 中身 |
|---|---|
| `pine/` | TradingView 用インジケーター・ストラテジー（`_v番号` ごとに保存） |
| `python/` | 1分足での探索・検証スクリプト |

## 最新版（v4）のロジック

- **ADXレジーム**：ADX（DI 14 / スムージング 14）が下限 33〜上限 45 の範囲にあるときだけ許可します。「状態フィルタ」ON なら、ADX が下限を下から上抜けた後に限ります。
- **シグナル（既定＝押し目）**
  - 買い：RCI(9, 終値) が +82 より上、かつ終値が前の足より下がった足
  - 売り：RCI が −82 より下、かつ終値が前の足より上がった足
  - 「順張り（±82突破）」「逆張り（±82から戻り）」も選べます。
- **逆神モード**：売買方向を反転します。
- **決済**：利確 7 pips / 損切り 6 pips / 時間切れ（分）。保有中に逆シグナルが出たらドテンします（ON/OFF可）。
- **約定**：確定足でシグナル → 次の足の始値でエントリー。TP/SL は足内の経路を「始値→近い方の高安→もう一方→終値」と仮定。
- **運用向けの任意機能**（既定 OFF）
  - 停止時間帯 5本（タイムゾーン指定）
  - N 連勝（M 分以内）でその日は終了
  - 集計開始日時

## オリジナルとの照合結果（JFX:USDJPY 10秒足、2026-10-30〜11-02）

- RCI・ADX の計算はオリジナルと一致（RCI は 99.9% の足で完全一致）。
- シグナル 53 回のうち、v4（押し目）で同じ足に出たのは 34 回、±2本以内では 42 回。
- 完全一致しない分は、10秒足の OHLC に現れない情報（短い足の値動きなど）をオリジナルが使っている可能性が高いです。

## 自動最適化ストラテジー（v5）

`pine/hiropi_skya_auto_strategy_v5.pine`

1. 候補（RCI期間 7,9,11,14,18 × 閾値 77,82,87 × ADX 25-45,33-45,33-60 × 逆神 OFF/ON ＝ 90通り）を、チャートの全期間で仮想売買し続けます。
2. 30分ごとに、各候補の直近48時間の損益を比べます。100pips（グラフ1.00）以上、取引5回以上、後半もプラス、の条件を満たす中で一番良い候補に切り替えます。満たす候補が無ければ様子見します。
3. 実際の売買は、そのとき選ばれている候補のシグナルだけで行います。ストラテジーレポートは「2日で選んで次の30分使う」方法そのものの、未来を見ない成績になります。

候補・間隔・評価期間・採用ラインはすべて入力で変えられます。シグナル表示用のインジケーターは v4 のままです。

## 実際のコストでの検証（cTrader 明細より、2026-11-05）

Axiory の cTrader 明細（0.1ロット・70回）では、手数料が1回あたり約95円（＝約0.95pips）。値幅は合計 −24.1pips、手数料込みで −9,042円。
コストを1回1.5pips（スプレッド＋手数料）として、固定パラメーター 7,200 通り（5ペア × RCI 5 × 閾値 3 × ADX 6 × 逆神 2 × 利確:損切り 8、ドテンなし）を
前半（2026年1〜6月）と後半（7〜9月）に分けて検証した結果、前半がプラスだったのは 0.1%、両方プラスは 1 通り（AUDJPY、ほぼ損益ゼロ）だけ。
利確・損切りの幅を広げるほど負けは小さくなるが（20:15 が最も小さい）、プラスにはならない。詳細は `results/2026_fixed_scan_cost1.5_*.csv`。

## Python の使い方（v14）

```bash
pip3 install numpy pandas numba

# 直近2日でパラメーター探索（5通貨ペア）
python3 python/hiropi_skya_optimize_v14.py search --data ./recent --out result_search

# 運用条件（タイ時間 03:00-06:30 停止・1時間で3連勝したら終了）で探索
python3 python/hiropi_skya_optimize_v14.py search --data ./recent --thai-stop --win-stop --out result_search

# 自動最適化（Pine v5 と同じ手順）を1分足で検証
python3 python/hiropi_skya_optimize_v14.py adaptive --data <1分足フォルダ> --from 2026-09-01 --to 2026-09-29 --out result_adaptive

# 「直前2日のベストを翌日に使う」方法そのものの検証
python3 python/hiropi_skya_optimize_v14.py walkforward --data <1分足フォルダ> --from 2026-07-01 --to 2026-09-29 --grid small --out result_wf
```

データは `<ペア小文字>*.csv`（`<TICKER>,<DTYYYYMMDD>,<TIME>,...` 形式、または TradingView 書き出しの `time,open,high,low,close`）。1分足・UTC。
